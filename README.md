# Aerogram Logistic OS

Мультитенантная платформа между информационными системами грузоотправителя
и транспортными компаниями: расчёт → выбор → создание → трекинг → документы → аналитика.

> Единая система управления всеми перевозчиками компании, которая автоматически
> выбирает оптимальный способ доставки по цене, сроку и риску.

Платформа принципиально **не является агрегатором-перепродавцом**: клиент подключает
свои действующие договоры с перевозчиками и работает по своим ставкам.

## Быстрый старт

Нужны: Docker, [uv](https://docs.astral.sh/uv/), pnpm, Python 3.12, Node 22.

```bash
cp .env.example backend/.env       # заполнить JWT_SECRET и CREDENTIAL_KEYS
make up                            # postgres, redis, mailpit, minio
make install                       # зависимости backend и frontend
make migrate                       # схема и политики RLS
make api                           # http://localhost:8000/docs
make front                         # http://localhost:5173
```

Сгенерировать ключ шифрования учётных данных перевозчиков:

```bash
cd backend && uv run python -c \
  "from aerogram.shared.crypto import CredentialCipher as C; print(C.generate_key())"
```

## Проверки

```bash
make lint     # ruff, mypy, import-linter, eslint
make test     # pytest (юнит + интеграционные)
make security # pip-audit, npm audit
```

Интеграционные тесты требуют PostgreSQL. Адрес берётся из `TEST_DATABASE_URL`;
без неё они пропускаются, а не падают.

## Ключевые принципы

* **Изоляция тенантов — в PostgreSQL**, не в приложении. Роль приложения без
  `BYPASSRLS`, RLS с `FORCE`, доступ к чужому объекту даёт `404`, а не `403`.
  См. ADR-0003 и `tests/integration/test_tenant_isolation.py`.
* **Ошибка перевозчика никогда не даёт `500`** — она становится строкой выдачи
  с кодом и русским текстом.
* **Деньги — `Decimal`, время — `TIMESTAMPTZ` в UTC**, срок — в рабочих днях.
  См. ADR-0006.
* **Границы модулей проверяются в CI.** `carriers` не знает о домене; домен
  обращается к перевозчикам только через `carriers.registry`.
* **Тесты пишутся вместе с кодом**, в той же задаче.

# Runbook

Пишется до того, как понадобится (раздел 12 ТЗ). Каждый сценарий — что случилось,
как понять, что делать, как проверить, что помогло.

## Готовые процедуры

Пока ни одна процедура не написана: они пишутся вместе с соответствующей
инфраструктурой, чтобы не описывать несуществующее.

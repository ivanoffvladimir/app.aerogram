Группа /typesOfDelivery/ — продукты и тарифы перевозки

Метод /typesOfDelivery/all/ — Перечень актуальных продуктов/тарифов перевозки, которые поддерживаются в API

Доступ

  • Зарегистрированные пользователи

Комментарии

  • Обращение к данному методу API осуществляется путём отправки запроса методом GET.
  • Выводятся продукты/тарифы, которые поддерживаются в API интеграции. Архивные продукты/тарифы из списка исключаются.
  • Некоторые методы API могут не поддерживать часть продуктов/тарифов. Наличие ограничений приведено в описании конкретных методов.

Формат запроса

// Пустой объект или null
{
}

# ПЭК — официальные примеры запросов

Архивы «Архив с примерами минимальных запросов» со страницы документации
`kabinet.pecom.ru/api/v1`, распакованы 4 сентября 2026 года. Имена файлов
в архивах записаны в cp866, поэтому при распаковке перекодированы.

Это **официальные тела запросов от перевозчика** — лучший материал для
фикстур, какой у ПЭК вообще есть: живого контура без договора у него нет,
а синтетический запрос легко разойдётся с настоящим в мелочи.

| Каталог | Что внутри |
|---|---|
| `CalculatePrice/` | 3 примера расчёта: терминал–терминал, с забором и доставкой, несколько грузомест |
| `CARGOPICKUP/` | 5 примеров заказа машины: физлицо/юрлицо, до терминала и до двери |
| `PREREGISTRATION/` | 9 примеров предварительного оформления, включая международную перевозку |

Единицы в примерах подтверждают документацию третий раз подряд:
`"weight": 46.32` — килограммы, `"length": 0.54` — метры, `"volume": 0.41` —
кубометры.

Чего в примерах нет — **ответов**. Только запросы. Значит фикстуры ответов
всё равно остаются синтетическими и помеченными (ADR-0010), а сверка с живым
контуром попадает в список при получении доступов.

Группа /netshop/ — прямые паллетные перевозки

Метод /netshop/submit/ — оформление заявки на прямые паллетные перевозки

Доступ

  • Зарегистрированные пользователи

Комментарии

  • Коды грузов и штрих-коды, возвращаемые этим методом являются предварительными и могут изменится при фактической приёмке груза
  • Для грузов нужно указывать код адреса получателя из справочника адресов получателей в поле cargos[].receiver.receiverAddrCode.

# Деловые Линии — источник не выкачан

Каталог пуст намеренно.

`dev.dellin.ru` из окружения разработки **достижим по сети**, но отвечает
`401` с `Server: QRATOR` и заголовком страницы **«Доступ к ресурсу ограничен»**
на все пути, включая корень. Проверено дважды: обычным HTTP-клиентом
и настоящим браузером (Chromium с исполнением JavaScript). Это не challenge,
который решается запуском скрипта, и не логин разработчика — это блокировка
диапазона IP облачного окружения.

Обходить её нечем и не нужно: она обращена к автоматам, а человек из своего
браузера открывает портал без препятствий.

**Что сюда положить** (ADR-0020, «Что требуется от человека», пункт 1):

* спецификацию, на которую ссылается Swagger UI со страницы
  `https://dev.dellin.ru/api/swagger/` — в интерфейсе это ссылка на `.json`
  или `.yaml`;
* коллекцию `https://dev.dellin.ru/api/postman_collection/`.

Рядом — строчку о том, откуда и когда выгружено.

# Техническое задание

## Действующая редакция — v3

`v3/` — финальный пакет ТЗ версии 3.0 (Logistics OS), принят как источник истины.

| Файл | Что это |
|---|---|
| `01-product.md` | Продуктовое ТЗ: цель, проблема, MVP scope, KPI пилота |
| `02-system.md` | Системное ТЗ: процессы, статусная модель, слой адаптеров |
| `03-frontend.md` | Требования к фронтенду |
| `04-backend.md` | Требования к бэкенду: архитектура, данные, API, адаптеры |
| `openapi.yaml` | **Контракт API.** Расхождение кода с этим файлом — ошибка кода |
| `erd.png` | Схема сущностей |
| `json-examples/` | Эталонные примеры запросов и ответов |
| `carrier-adapter-matrix.csv` | Пять перевозчиков: протокол, авторизация, возможности |
| `competitive-matrix.xlsx` | Конкурентный анализ |
| `README_START_DEVELOPMENT.txt` | Порядок старта разработки от автора ТЗ |

Файлы `*.docx` — оригиналы, из которых сгенерированы markdown-версии.
Правится оригинал, markdown перегенерируется; расходиться они не должны.

## Архив — v1

`archive-v1/` — ТЗ, по которому велась разработка до 30 августа 2026 года
(MVP-0: один перевозчик СДЭК, один тенант, режим `own_contract`).

Хранится не из сентиментальности: по нему написаны недели 1–5, и при разборе
старого кода нужно понимать, каким требованиям он отвечал. **Новый код по нему
писать нельзя.** Разбор расхождений и решения по ним — ADR-0011…0014.
